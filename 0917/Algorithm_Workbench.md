4. DWORD 타입의 변수를 선언하고 음수 값을 할당할 수 있는지 확인하세요. 이것이 어셈블러의 타입 검사(type checking)에 대해 무엇을 알려주나요?
* Find out if you can declare a variable of type DWORD and assign it a negative value. What does this tell you about the assembler’s type checking?
* Answer:
* **결과:** 선언 및 음수 값 할당이 문제없이 가능합니다. (예: `val1 DWORD -5`)
* **의미:** MASM 어셈블러의 타입 검사는 변수의 크기(메모리 바이트 수)만 엄격하게 검사하며, 부호(signed vs unsigned) 개념을 엄격하게 구별하지 않습니다. 음수 값을 전달하면 지정된 크기(32비트)의 2의 보수 형태로 비트열이 메모리에 그대로 저장됩니다.




5. (1) EAX 레지스터에 숫자 5를 더하는 명령어와 (2) EDX 레지스터에 5를 더하는 명령어 두 개를 포함하는 프로그램을 작성하세요. 리스팅 파일을 생성하여 어셈블러가 생성한 기계어를 확인하고, 두 명령어 사이에 어떤 차이점이 있는지 설명하세요.
* Write a program that contains two instructions: (1) add the number 5 to the EAX register, and (2) add 5 to the EDX register. Generate a listing file and examine the machine code generated by the assembler. What differences, if any, did you find between the two instructions?
* Answer:
* **코드 예시:**
```assembly
ADD EAX, 5
ADD EDX, 5

```


* **기계어 비교 (Listing file 결과):**
* `ADD EAX, 5` $\rightarrow$ `05 00000005`
* `ADD EDX, 5` $\rightarrow$ `81 C2 00000005`


* **차이점 설명:** IA-32 아키텍처에서 EAX 레지스터는 누산기(Accumulator)로서 자주 사용되는 특수 레지스터입니다. 따라서 `ADD EAX, imm32`는 단축된 전용 1바이트 림코드 `05`를 사용하는 반면, `ADD EDX, imm32`는 일반 레지스터용 2바이트 림코드 `81 C2`를 사용합니다.

15. 다음 doubleword 변수 `val1 DWORD 87654321h`에 대해 메모리(낮은 주소에서 높은 주소 순)에 저장되는 개별 바이트의 순서를 보여주세요.
* Show the order of individual bytes in memory (lowest to highest) for the following doubleword variable: `val1 DWORD 87654321h`
* Answer:
* x86 아키텍처는 리틀 엔디안(Little-endian)을 사용하므로 최하위 바이트(LSB)부터 저장됩니다.
* **가장 낮은 주소 $\rightarrow$ 가장 높은 주소:** `21h, 43h, 65h, 87h`
