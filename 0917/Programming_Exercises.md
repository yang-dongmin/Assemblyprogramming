1. 정수 수식 계산 (Integer Expression Calculation)
* Using the AddTwo program from Section 3.2 as a reference, write a program that calculates the following expression, using registers: A = (A + B) − (C + D). Assign integer values to the EAX, EBX, ECX, and EDX registers.
* **해석:** 3.2절의 AddTwo 프로그램을 참고하여, 레지스터를 사용해 다음 수식을 계산하는 프로그램을 작성하세요: A = (A + B) − (C + D). EAX, EBX, ECX, EDX 레지스터에 정수 값을 할당하세요.
* Answer:
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess proto, dwExitCode:dword

.code
main proc
    ; 레지스터 초기값 할당 (A = EAX, B = EBX, C = ECX, D = EDX)
    mov eax, 15    ; A = 15
    mov ebx, 10    ; B = 10
    mov ecx, 5     ; C = 5
    mov edx, 3     ; D = 3

    ; 수식 계산: A = (A + B) - (C + D)
    add eax, ebx   ; EAX = A + B (15 + 10 = 25)
    add ecx, edx   ; ECX = C + D (5 + 3 = 8)
    sub eax, ecx   ; EAX = (A + B) - (C + D) (25 - 8 = 17)

    invoke ExitProcess, 0
main endp
end main

```

5. AddTwoSum의 리스팅 파일 분석 (Listing File for AddTwoSum)
* Generate a listing file for the AddTwoSum program and write a description of the machine code bytes generated for each instruction. You might have to guess at some of the meanings of the byte values.
* **해석:** AddTwoSum 프로그램에 대한 리스팅 파일을 생성하고, 각 명령어에 대해 생성된 기계어 코드 바이트의 설명을 작성하세요. 바이트 값의 일부 의미는 추측해야 할 수도 있습니다.
* Answer:
* **생성된 리스팅 파일 주요 코드 및 기계어 헥사 코드 분석:**
```text
00000000  B8 00000005          mov eax, 5
00000005  83 C0 06             add eax, 6
00000008  A3 00000000 R        mov sum, eax

```


* **기계어 바이트 해석:**
* `B8 00000005`: `B8`은 `mov eax, imm32`를 나타내는 림코드(Opcode)이며, 뒤의 `00000005`는 32비트 리틀 엔디안 형식으로 표현된 정수 값 `5`입니다.
* `83 C0 06`: `83 C0`은 8비트 즉시 값(Immediate value)을 EAX 레지스터에 더하는 `add eax, imm8` 명령어 림코드이며, `06`은 더해질 피연산자 값 `6`입니다.
* `A3 00000000 R`: `A3`은 EAX의 값을 메모리 주소로 직접 이동시키는 `mov [mem], eax` 림코드입니다. `00000000`은 `sum` 변수의 오프셋 주소이고, 뒤의 `R`은 링커에 의해 최종 실행 메모리 주소가 결정됨을 뜻하는 재배치(Relocatable) 표시입니다.






6. AddVariables 프로그램 수정 (AddVariables Program)
* Modify the AddVariables program so it uses 64-bit variables. Describe the syntax errors generated by the assembler and what steps you took to resolve the errors.
* **해석:** 64비트 변수를 사용하도록 AddVariables 프로그램을 수정하세요. 어셈블러에 의해 발생한 구문 오류와 이를 해결하기 위해 취한 조치를 설명하세요.
* Answer:
* **원인 및 구문 오류 분석:**
32비트 MASM 환경(`.386` 또는 `.model flat`)에서 `QWORD`(64비트) 변수 간에 `mov eax, var64`나 `add eax, var64_2`와 같은 명령어를 사용하면 **"invalid instruction operands"** 또는 **"operand types do not match"** 구문 오류가 발생합니다. 32비트 x86 레지스터(`EAX`)는 64비트 메모리 피연산자를 직접 수용할 수 없기 때문입니다.
* **오류 해결 단계:**
1. 64비트 변수는 상위 32비트와 하위 32비트로 나누어 연산해야 합니다.
2. 하위 32비트 연산에는 `ADD` 명령어를 사용하고, 상위 32비트 연산에는 이전 연산에서 발생한 캐리(Carry)를 함께 더해주는 `ADC` (Add with Carry) 명령어를 사용하도록 수정합니다.


* **수정된 코드:**
```assembly
.386
.model flat, stdcall
.stack 4096
ExitProcess proto, dwExitCode:dword

.data
var1 QWORD 1234567890ABCDEFh
var2 QWORD 1111222233334444h
sum  QWORD ?

.code
main proc
    ; 1. 하위 32비트 더하기
    mov eax, dword ptr [var1]
    add eax, dword ptr [var2]
    mov dword ptr [sum], eax

    ; 2. 상위 32비트 더하기 (캐리 포함)
    mov eax, dword ptr [var1 + 4]
    adc eax, dword ptr [var2 + 4]
    mov dword ptr [sum + 4], eax

    invoke ExitProcess, 0
main endp
end main

```
