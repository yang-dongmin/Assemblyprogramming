## 1. 컴퓨터란? (What is a Computer?)
컴퓨터란 데이터를 입력받아 정해진 명령어에 따라 처리하고, 그 결과를 출력하는 전자 장치입니다.

### 핵심 동작 프로세스
$$\text{입력 (Input)} \longrightarrow \text{처리 (Process)} \longrightarrow \text{저장 (Storage)} \longrightarrow \text{출력 (Output)}$$

- **예시:** 키보드로 글자 입력 $\rightarrow$ CPU가 처리 $\rightarrow$ 메모리에 저장 $\rightarrow$ 모니터 화면에 결과 출력

---

## 2. CPU란? (Central Processing Unit)
CPU(Central Processing Unit)는 컴퓨터의 중앙 처리 장치로, 프로그램의 명령어를 해석하고 실행하는 핵심 부품입니다. 흔히 **컴퓨터의 뇌**라고 표현합니다.

### 주요 역할
1. 프로그램의 명령어 가져오기 (Fetch)
2. 명령어 해석하기 (Decode)
3. 계산 및 논리 연산 수행하기 (Execute)
4. 다른 장치에 작업 지시하기 (Control)

> **요약:** 컴퓨터가 실제로 어떤 일을 할지 결정하고 실행하는 장치입니다.

---

## 3. Memory란? (RAM & Storage)
Memory(메모리)는 컴퓨터가 데이터를 저장하고 필요할 때 빠르게 사용할 수 있도록 하는 공간입니다. 대표적으로 **RAM(Random Access Memory)**이 있습니다.

RAM은 현재 실행 중인 프로그램이나 데이터를 임시로 저장합니다.

### 프로그램 실행 과정 예시 (게임 실행 시)
1. 게임 파일 로드 (저장장치: SSD/HDD)
2. 메모리에 배치 (주기억장치: RAM)
3. 데이터 처리 및 실행 (연산장치: CPU)

> **특성 (휘발성):** RAM은 속도가 매우 빠르지만, 컴퓨터 전원이 꺼지면 저장된 내용이 사라집니다.  
> **요약:** CPU가 작업하는 데 필요한 데이터를 잠시 올려두는 **작업 공간(책상)**입니다.

---

## 4. Debug란? (Debugging)
Debug(디버그)란 프로그램에서 발생하는 오류(Bug)를 찾고 원인을 분석하여 수정하는 과정입니다.

### 프로그램 오류의 유형
- 문법 오류 (Syntax Error)
- 논리 오류 (Logic Error)
- 실행 중 오류 (Runtime Error)
- 예상과 다른 결과 출력

### 디버깅 프로세스
$$\text 문제 발생 \longrightarrow \text 원인 추적 \longrightarrow \text 코드 분석 \longrightarrow \text 수정 \longrightarrow \text 테스트 및 검증$$

> **예시:** 프로그램이 특정 줄에서 멈춘다면 브레이크포인트(Breakpoint)를 설정하고, 변수의 값과 실행 흐름을 확인하며 문제를 해결합니다.  
> **요약:** 프로그램이 왜 예상대로 동작하지 않는지 찾아 수정하는 과정입니다.

## 5. AI 시대에서 왜 Assembly를 배워야 하나?
AI가 고수준 코드를 자동으로 작성해 주는 시대일수록, **컴퓨터가 실제로 어떻게 동작하는지 이해하는 하위 계층(Low-level) 이해 능력**이 훨씬 더 중요해집니다.

어셈블리(Assembly)를 배우면 고급 언어(Python, C++, Java 등)가 결국 CPU가 이해할 수 있는 기계어 명령어로 변환되어 실행되는 전체 메커니즘을 파악할 수 있습니다.

### 어셈블리를 배워야 하는 이유
- **CPU 동작 원리 파악:** CPU가 명령어를 실제로 어떻게 처리하는지 이해할 수 있음
- **하드웨어 제어 이해:** 레지스터(Register)와 메모리의 세부 동작을 파악할 수 있음
- **딥 디버깅 & 성능 최적화:** 프로그램 실행 과정을 최하위 단에서 추적하고 성능 병목을 해결할 수 있음
- **AI 코드 검증 역량:** AI가 생성한 코드의 내부 실행 구조를 판단하고 비효율성을 개선할 수 있음

> **결론:** 단순히 "코드를 작성하는 능력"보다 **AI가 만든 코드가 실제 내부에서 어떻게 동작하는지 이해하고 검증하는 능력**이 핵심이 됩니다. 어셈블리는 컴퓨터의 가장 낮은 수준의 동작 원리를 파악하기 위한 필수 도구입니다.
